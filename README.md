# 📘 Edu Tutor AI

An AI-powered educational assistant built using **Gradio**, **Hugging Face Transformers**, and **IBM Granite 3.2B Instruct Model**.  
This project helps students learn concepts, generate summaries, create flashcards, quizzes, and even convert responses into speech.

---

## 🚀 Features

- 📖 **Concept Explanation**
  - Explains topics in detail with examples

- 📑 **Topic Summarization**
  - Generates concise bullet-point summaries

- 🎴 **Flashcard Generator**
  - Creates study flashcards automatically

- 📝 **Quiz Generator**
  - Generates MCQs, True/False, and Short Answer questions

- 🔊 **Text-to-Speech**
  - Converts generated responses into audio using gTTS

- ⬇️ **Download Output**
  - Save generated content as text files

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/Edu_Tutor_AI.git
cd Edu_Tutor_AI
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
python Edu_Tutor_AI.py
```

After running, Gradio will generate a local URL and optionally a public shareable link.
